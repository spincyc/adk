# Ultrasonic range with explicit validity

Publication state: **software prepared; exact specimen required before power**
Energy class: **E1** — USB-powered Mega 2560, identified ultrasonic module, and
resistor-limited evidence LEDs

This lesson treats distance as a qualified observation:

`trigger pulse → Echo/TP-E width → RangeState → visible range evidence`

A number alone is not a reading. `Valid`, `Timeout`, and `OutOfRange` remain
different results. The deterministic, non-owning `UltrasonicRanger` consumes
caller-supplied microsecond timestamps and Echo levels; the sketch's endpoints
own the physical Trigger and Echo pins.

## The range hunt

The payoff is immediate and cumulative:

1. all three LEDs sparkle for 150 ms;
2. a face-on card earns green;
3. rotating the same card makes red win, and returning it restores green;
4. an optional complete-but-excluded Echo earns amber;
5. at two minutes every light turns off and every pin is released.

Each win depends on the same Trigger → Echo → classification path.

## Parts and wiring

- Arduino Mega 2560 powered by USB
- one identified Elegoo EL-SM-001, or no powered bench work
- three LEDs, each with its own 220 Ω or larger resistor
- flat cardboard target
- logic probe or oscilloscope for Echo/TP-E

| Signal | Mega pin | Connection |
|---|---:|---|
| Trigger | D40 | module Trigger |
| Echo / TP-E | D41 | module Echo and high-impedance probe |
| Valid evidence | D45 | jumper to a6; LED anode a6, cathode a8; 220 Ω a8 to GND rail |
| Out-of-range evidence | D46 | jumper to a12; LED anode a12, cathode a14; 220 Ω a14 to GND rail |
| Fault evidence | D47 | jumper to a18; LED anode a18, cathode a20; 220 Ω a20 to GND rail |
| Supply | 5 V, GND | module VCC and GND |

Use this wiring only for a verified 5 V module and the 5 V Mega 2560. Remove
USB power before wiring or attaching probe clips. The orientation drawing is
illustrative; this table and the printable schematic are authoritative.

### Specimen gate

The repository does not contain a recorded photograph, label, lot, or revision
for the learner's module. The circuit is therefore conditional on an Elegoo
EL-SM-001. Elegoo's product page identifies that model and specifies a 5 V DC
supply. If the physical specimen and its primary documentation do not match,
do not power the module. An HC-SR04-shaped clone
does not inherit another manufacturer's ratings.

## Public model

`UltrasonicRangerConfig` fixes the Echo timeout, maximum accepted pulse,
minimum and maximum distance, and assumed sound speed. The first supported
example uses 30 ms for both timing bounds, 20–4000 mm, and 343 µm/µs.

| Operation | Meaning |
|---|---|
| `initialize()` | Return `Status`; validate configuration and initialize the deterministic pulse model |
| `startMeasurement(now, echoHigh)` | Return `Status`; arm one measurement from an explicit timestamp and initial Echo level |
| `update(now, echoHigh)` | Return `Status`; advance the measurement from one supplied observation |
| `reading()` | Return the stable state, distance, Echo duration, and validity |
| `reset()` | Retain initialization and restore the inert reading state |

Check each returned `Status` with `.ok()` and pass the whole status to failure
observation or policy code. The 20–4000 mm interval is an application
classification bound, not an accuracy claim or a substitute for the
identified specimen's operating limits.

The sketch composes `DigitalOutput`, `DigitalInput`, three `MonoLed` objects,
and the ranger. Its `loop()` reads as observe, decide, show, then request the
next measurement. Every terminal result—including `Valid`—is replaced by a
new request at the 60 ms cadence, so a successful distance cannot become
silently stale. The required 10 µs Trigger pulse is the only bounded delay;
the ranging model and measurement cadence are otherwise nonblocking.

## Predict, observe, interpret

The three evidence LEDs first illuminate together for 150 ms. That visible
sparkle catches a backwards or misplaced LED before ranging begins:

| Result | Visible evidence |
|---|---|
| waiting for Echo | all three LEDs off |
| valid distance | D45 on |
| complete pulse outside 20–4000 mm | D46 on |
| no valid Echo before timeout | D47 on |

Before power, use the matched specimen documentation to predict TP-E's idle
level and its high pulse after Trigger. Attach the probe to D41/TP-E and Mega
GND while unpowered. Observe Trigger and Echo together if the instrument has
two channels.

Interpret a complete Echo pulse as evidence that the module returned timing
information. Compare the measured high time with
`distance ≈ echoMicroseconds × 343 / 2000` millimetres. Agreement with D45 or
D46 supports classification; it does not establish calibrated accuracy.

A red LED and no Echo rise support `Timeout`. A red LED does not identify
wiring, target geometry, module identity, or acoustic conditions by itself.
For safe-state evidence, stop the sketch and measure Trigger low before its pin
returns high impedance. An extinguished evidence LED does not prove that state.

The sketch has an input-independent two-minute deadline. It drives Trigger low,
turns every light off, and releases all five endpoints even if Echo is stuck or
absent.

## Physical claim boundary

This publication records no physical observation. Exact module identity and
primary documentation are required before powering the conditional circuit.
