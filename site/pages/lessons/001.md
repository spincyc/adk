# Digital output

Status: **host verified; Mega hardware acceptance pending**

`DigitalOutput` is the first debugging primitive. It owns one pin, writes the
initial latch before enabling output, and returns the pin to high impedance
before releasing its claim.

```cpp
adk::Runtime       runtime;
adk::DigitalOutput led (runtime.resources (), LED_BUILTIN);
```

The example blinks the Mega 2560 built-in LED. No external wiring is required.
The PDF adds prediction, trace, fault, measurement, and sign-off worksheets.
