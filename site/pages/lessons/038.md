# Lesson 038 — acoustic envelope

Status: **host verified; reference-fixture bench acceptance open**

Energy class: **E0 copied observations; provisional E1 reference fixture**
Safety boundary: **relative evidence only; no recording, SPL, or surveillance**

`AcousticEnvelope` turns supplied analog-envelope and optional gate samples
into one bounded event:

`sample → quiet baseline → event window → unitless intensity`

The behavior owns no pin, ADC, interrupt, timer, heap, callback, or hidden
clock. The canonical Mega sketch defaults to a deterministic copied trace, so
the complete software experiment works without acoustic hardware.

## Exact reference fixture

The optional physical route is the SparkFun `SEN-12642` Sound Detector with
visible `V10` silkscreen, matched to SparkFun hardware V1.0. Use one common
USB-powered 5 V state:

| Detector net | Mega connection | Role |
|---|---|---|
| `VCC` | `5V` | common supply |
| `GND` | `GND` | common reference |
| `ENVELOPE` | `A0`, named `TP-E` | analog authority |
| `GATE` | `D22`, named `TP-T` | optional active-high threshold evidence |
| `AUDIO` | not connected | outside this lesson |

`GATE` is a driven push-pull output, so D22 uses no pull-up. `ENVELOPE` is
sampled against the Mega AVcc reference. The detector must not remain powered
while the Mega is unpowered. Incoming revision matching, output-range
measurements, and all physical acceptance remain open.

This reference does not identify or authorize a look-alike microphone board,
KY-037/KY-038, or an unknown Elegoo module.

## Baseline and event window

The first healthy, non-clipped sample establishes a quiet baseline. During
calibration and quiet:

`baseline += (raw - baseline) / 2^baselineShift`

Signed division truncates toward zero. The baseline freezes during an event
and refractory interval. Amplitude is the absolute difference between the
sample and baseline.

Attack requires amplitude at or above the configured attack offset. Release
requires amplitude at or below a smaller offset. The event retains its greatest
supplied amplitude and closes at the earlier of continuous quiet for
`quietToClose` or exact `eventWindow` expiry.

Only completion publishes `relativeIntensity`, an integer from 0 through 1000
within one configuration. It is not dB SPL, loudness, frequency, source
identity, force, damage, or a value comparable across modules, gain settings,
rooms, or baselines.

## Quality and faults

Rail-margin samples fault as `ClippedLow` or `ClippedHigh`. Failed sources are
never interpreted. With threshold input configured, one analog/gate mismatch
is visible evidence; a mismatch sustained for `quietToClose` becomes
`ThresholdDisagreement`. Analog `ENVELOPE` remains the event and intensity
authority.

Recovery from clipping, source failure, threshold disagreement, or malformed
runtime evidence requires `reset()` and fresh calibration. Identical same-time
frames are idempotent. Changed same-time evidence, backward time, and an
unsigned half-range jump fault without partial mutation.

## Board-visible deterministic experiment

The default sketch repeats a fixed midrail, attack, peak, release, and quiet
trace. It advances evidence time by 20 ms while presenting each frame for
250 ms. Reference-fixture mode instead timestamps each acquired physical
sample with real elapsed `millis()`; it never substitutes the fixture clock.

| Evidence | Meaning |
|---|---|
| D30 through 1 kΩ | a bounded event completed on this frame |
| D31 through 1 kΩ | copied active-high gate evidence |
| D32 through 1 kΩ | envelope behavior is not in Fault |

Before the first event, D30 and D31 are off as the safe inactive output
evidence. D32 turns on only after the resources required by the selected path
and the envelope behavior initialize successfully. Physical mode owns and
acquires A0 through `AnalogInput` and D22 through a no-pull `DigitalInput`
before any indicator; the absent-hardware trace acquires no physical source
and D32 makes no such claim. Predict D31 during the attack and peak, then one
D30 completion pulse after continuous quiet. Shutdown releases outputs first,
then physical inputs, then resets behavior. Test D30, D31, and D32 at their
pin-side test points for inactive/high-impedance state. Host tests establish
resource release; LED darkness alone does not. Serial is neither used nor
required.

The trace proves deterministic behavior only. It does not prove microphone
operation, ADC bandwidth, acoustic capture, privacy properties, SPL, or
physical acceptance.

## Predict, observe, interpret

1. Predict the baseline from the first midrail sample and no event before the
   exact calibration boundary.
2. Predict which attack-minus-one, exact-attack, and attack-plus-one frames can
   open an event.
3. Predict equal amplitude for equal positive and negative excursions.
4. Retain a larger peak, then close once through quiet and once through maximum
   window expiry in host traces.
5. Predict faults at both clipping boundaries.
6. Compare one threshold mismatch with sustained disagreement.
7. Place a pulse wholly between sample times and explain why no evidence
   captures it.
8. Shut down and verify LED inactivity and resource release separately.

Never request a loud or startling stimulus. Remove USB for heat, odor,
unexpected reset, unstable rail, excessive current, or disagreement between
the visible V10 board and the pinned reference sources.
