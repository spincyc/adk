# Character display and stable records

Status: **host verified; hardware acceptance open**  
Energy class: **E1** — USB-powered, low-current display circuit

Lesson 014 keeps four concerns separate:

`climate state → presentation choice → character display`

`climate state → stable machine record`

`Hd44780Display` owns RS, E, and D4–D7 on an HD44780-compatible 16×2 LCD.
Its caller-time startup is explicit, and each later `update(now)` flushes at
most one changed cell. `show(row, text)` changes the desired presentation; it
does not change the climate sample.

`formatClimateRecord()` emits fixed-order ASCII fields with integer units:

```text
seq=42,state=valid,temp_centi_c=-125,rh_permille=456,at_ms=4294967290
```

It allocates nothing, does not use locale, distinguishes every sample state,
and reports a small caller buffer. Serial is an optional carrier for that
record, not the circuit's only evidence.

## Predict, observe, interpret

Predict the first two LCD lines and record sequence before powering the
circuit. Observe D13 first: it turns on only after all resources are acquired.
Then observe the LCD's four fixed views and TP14 at LCD E while cells change.

Interpret the three paths separately:

- D13 on proves setup acquired its resources.
- LCD text proves the current human presentation became visible.
- TP14 pulses prove transport activity, not readable contrast or correct data.

On shutdown, D13 turns off and D22–D27 are released. The LCD may retain old
pixels; measure a named signal pin to prove high impedance instead of treating
retained text as ownership evidence.

## Wiring

Use a Mega 2560 and an identified HD44780-compatible 16×2 module:

| LCD function | Mega path |
|---|---|
| VSS / VDD | GND / 5 V |
| VO | wiper of 10 kΩ potentiometer between 5 V and GND |
| RW | GND |
| RS | D22 |
| E / TP14 | D23 |
| D4–D7 | D24–D27 |
| D0–D3 | unconnected |

Identify the exact module and pin-one mark before wiring. Do not assume the
backlight includes a resistor; leave A/K disconnected until its primary
documentation establishes polarity and current limiting. Disconnect USB for
every wiring change.

## CLI workflow

```sh
make host-test
make host-test-sanitize
make arduino-Lesson014CharacterDisplay
make monitor PORT=/dev/ttyACM0 BAUD=115200
```

The first three commands are software evidence. The serial target can show
stable records but cannot replace D13, LCD, TP14, or released-pin observations.
