# Lesson 033 — calibration console

Status: **host verified; physical acceptance open**  
Energy class: **E1** — USB-powered Mega, passive controls, and
resistor-limited indicators  
Safety boundary: **calibration values only; no storage or actuator output**

Lesson 033 composes the calibrated joystick from Lesson 031 and quadrature
encoder from Lesson 032:

`raw controls → interpreted events → bounded preview → explicit commit or cancel`

The joystick chooses the minimum or maximum field and supplies a coarse
preview. Encoder edges trim the selected value one unit at a time. Joystick
Select commits both values atomically; the encoder button cancels and restores
the committed pair. No value is written to EEPROM, and no value drives a
motor, servo, relay, heater, or other load.

## Contract and state

`CalibrationConsole` is a hardware-neutral, fixed-storage state machine. It
borrows no endpoints and performs no I/O. Its caller supplies time and one
`CalibrationConsoleInput`, then reads a stable
`CalibrationConsoleSnapshot`.

| State | Meaning | Visible state indication |
|---|---|---|
| Selecting | choose Minimum or Maximum | blue RGB |
| Editing | change only the selected preview field | amber RGB |
| Committed | acknowledgement; committed pair changed atomically | green RGB |
| Cancelled | acknowledgement; preview restored | violet RGB |
| Fault | input, time, configuration, or invariant failure | red RGB |

In `Selecting`, X below −500 chooses Minimum and X above 500 chooses Maximum.
The center band retains the prior selection. Select enters `Editing` with a
fresh copy of both committed values.

In `Editing`, Y outside −500…500 maps to a coarse candidate across the
configured legal range. Returning Y to center holds that candidate. The
encoder delta is then applied as a one-unit trim. The pair always obeys:

`lowerLimit ≤ minimum ≤ maximum − minimumSeparation`

`minimum + minimumSeparation ≤ maximum ≤ upperLimit`

Select commits the pair. Cancel wins over a simultaneous Select, restores both
preview values, and enters `Cancelled`. After the configured acknowledgement
duration, `Committed` and `Cancelled` return to `Selecting`.

Invalid input, backward non-wrapping time, or impossible configuration enters
`Fault`; no fault path commits a value. Recovery requires explicit shutdown
and reinitialization. Shutdown clears transient events while leaving the last
committed pair inspectable.

## Adapter and evidence boundary

The canonical Mega sketch is an adapter around the value-only engine:

```text
setup: acquire inputs → acquire indicators → initialize console → show ready
loop:  observe controls → decide calibration → present preview
```

Presentation consumes a snapshot. It cannot call back into the engine or
silently change a calibration value. The LCD shows the selected field,
committed value, and preview value. Four resistor-limited LEDs show the high
nibble of the selected preview, so the experiment remains observable if the
LCD adapter fails. The RGB LED communicates the state listed above. A piezo
cue, when fitted, is supplemental.

The canonical fixture reserves these Mega pins:

| Role | Mega pin(s) | Connection |
|---|---|---|
| joystick X / TP-X | A0 | inspected module X output |
| joystick Y / TP-Y | A1 | inspected module Y output |
| joystick Select | D22 | inspected module switch output |
| encoder A / TP-A | D24 | inspected module A/CLK output |
| encoder B / TP-B | D25 | inspected module B/DT output |
| encoder Cancel button | D26 | inspected module switch output |
| preview nibble | D27–D30 | each pin → 1 kΩ → LED anode; cathode → GND |
| 16×2 LCD | D31–D36 | RS, EN, D4, D5, D6, D7 |
| common-cathode RGB | D5–D7 | one 330 Ω resistor per channel |

The exact inspected-module record determines the supply, ground, and signal
pin order. This table does not authorize wiring an unidentified lookalike.

The input evidence points are:

| Test point | Signal | What it can establish |
|---|---|---|
| TP-X | joystick horizontal wiper to Mega GND | raw field-selection input |
| TP-Y | joystick vertical wiper to Mega GND | raw coarse-preview input |
| TP-A | encoder A/CLK to Mega GND | one phase of the Gray-code sequence |
| TP-B | encoder B/DT to Mega GND | the other phase of the Gray-code sequence |

These points do not by themselves prove the interpreted event or committed
value. Reconcile them in order:

`test points → component snapshots → console snapshot → LCD/RGB/LED presentation`

Resource acquisition and safe state are separate claims. The startup
acquisition pattern establishes that each presentation endpoint initialized.
The later all-indicators-inactive observation establishes the commanded
shutdown state. Neither observation alone proves that the input and output
pins were released to high impedance.

## Predict, observe, interpret

1. With USB disconnected, identify the exact joystick and encoder revisions.
   Check every marking and pin label against their qualified records. Do not
   infer a KY-series pinout from appearance or a retail kit name.
2. Verify the joystick supply and ground, TP-X, TP-Y, encoder TP-A and TP-B,
   every LED resistor, common-cathode RGB polarity, and common ground.
3. Predict Minimum remains selected while X is centered. Apply USB power,
   observe blue, and reconcile TP-X with the joystick snapshot.
4. Move X past the positive threshold. Predict Maximum; observe the LCD field
   and retain the field when X returns to center.
5. Press joystick Select. Predict amber with preview equal to committed.
   Move Y beyond its threshold and observe a coarse preview change on both LCD
   and the four-LED nibble.
6. Rotate one valid encoder edge sequence. Predict exactly one unit of trim.
   Reconcile TP-A/TP-B order, encoder count, preview, and the LED nibble.
7. Press joystick Select. Predict one atomic commit, green acknowledgement,
   and no half-updated pair.
8. Begin another edit, change both presentation values, then press the encoder
   button. Predict violet acknowledgement and exact restoration of both
   committed values.
9. Present Select and Cancel together. Predict Cancel wins and nothing commits.
10. Invoke shutdown separately. Observe inactive presentation, then use the
    named release method to check input high impedance before removing USB.

Stop and remove USB power for a hot part, unstable supply, wrong polarity,
missing resistor, out-of-rail test-point reading, unexpected output, or any
disagreement between the exact pin table and the breadboard. Software
shutdown is not the physical stop.

## Deterministic replay

The host tests supply every timestamp and input. They cover every state,
threshold, clamp, acknowledgement boundary, rollover case, simultaneous event,
invalid range, fault, restart, and shutdown. Replaying the same input/time
recording must produce byte-identical snapshots.

The learner-facing story depends on both earlier lessons: enter Editing with
the joystick, commit one changed preview, begin another edit, then cancel it
with the encoder switch. LCD, RGB, and nibble lamps expose every payoff. At
120 seconds all owners shut down regardless of state or held input.

Repository automation owns replay, lifecycle, Mega, size, PDF, and site gates.
Those maintainer checks are not learner chores and do not establish physical
acceptance.
