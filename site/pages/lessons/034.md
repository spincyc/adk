# Lesson 034 — magnetic observations

Status: **host verified; exact-revision wiring and physical acceptance open**

Energy class: **E0 in host tests; provisional E1 fixture after qualification**
Safety boundary: **inert observation only; no motion or actuation**

Lesson 034 preserves the evidence chain:

`raw sample → qualified range and continuous dwell → stable magnetic observation`

`LinearHall` owns one analog input. `MagneticContact` owns one digital input.
Each samples exactly once per explicit-time update and publishes a stable
`MagneticObservation`.

The authorized inventory lists `Linear Hall` and `Magnetic Spring` product
families. It does not establish output type, pin order, supply, pull-up rail,
active level, transfer curve, or polarity. Keep an exact specimen unpowered
until markings and primary electrical evidence resolve those facts.

## Observation values

Every snapshot retains:

| Field | Meaning |
|---|---|
| `source` | `LinearAnalog` or `ContactDigital` |
| `raw` | ADC count, or canonical zero/one contact value |
| `rawLevel` | always Low for analog; retained Low/High for contact |
| `observedAt` | caller-supplied sample timestamp |
| `polarity` | Negative/Neutral/Positive for linear; Unspecified for contact |
| transition events | activation and deactivation from the latest update |
| `active`, `stableFor` | stable interpretation and its modular duration |
| `quality` | Unqualified, Valid, below range, or above range |
| `status` | lifecycle or time-contract result |

Before the first successful update, the snapshot is unqualified and reports
`NotInitialized`. Out-of-range analog evidence clears a pending dwell
candidate without claiming an open circuit, short circuit, absent magnet, or
damaged module.

## Linear thresholds

Valid configuration requires:

`qualifiedMin ≤ negativeActivate < negativeRelease < positiveRelease < positiveActivate ≤ qualifiedMax ≤ 1023`

The activate/release separation supplies hysteresis. A new candidate must
persist continuously for `dwell`. Direct Negative-to-Positive travel must
qualify Neutral first: deactivation and the new activation occur in separate
dwell intervals.

`reversePolarity` swaps the reported Negative and Positive labels after
interpretation. It never changes the retained raw sample.

## Contact limits

The contact configuration explicitly supplies its pull policy, closed level,
and dwell. Polarity remains `Unspecified`. One constant digital level cannot
distinguish a steady stimulus from a stuck, shorted, or disconnected circuit.
Those diagnoses require independent electrical evidence.

## Lifecycle and time

Construction is inert. Initialization validates configuration and Mega
capabilities before claiming the pin. Repeated initialization is inert.
Shutdown and destruction release the input idempotently.

Unsigned modular time advances only when elapsed time is strictly below
`0x80000000` milliseconds. Natural 32-bit rollover is valid. An exact
half-range or larger apparent jump reports `InvalidArgument` without sampling
or changing transition state.

## Provisional evidence fixture

No powered wiring is authorized until the exact specimens are qualified.
After qualification, the reference roles are:

| Role | Mega connection |
|---|---|
| Linear-family output / `TP-H` | A0 / D54 |
| Contact-family output / `TP-R` | D22 |
| Qualified-range witness | D30 LED through 1 kΩ |
| Contact-state witness | D31 LED through 1 kΩ |
| Ready/fault witness | D32 LED through 1 kΩ |

Each direct LED is bounded to at most 5 mA by its 1 kΩ path. That does not
include module current or the Mega baseline. Exact module, pin, port, rail, and
aggregate current limits remain open.

The pencil drawing in the printable lesson is an inspection path, not an
electrical schematic. An authoritative schematic remains blocked until the
selected specimens are identified.

## Predict, observe, interpret

1. With USB absent, predict which marking or primary source establishes every
   specimen role. Stop if any role remains inferred.
2. Predict idle values at `TP-H` and `TP-R` and the three LED current paths.
3. Apply USB only to a qualified fixture. Interpret the ready witness as
   acquisition evidence, not sensor correctness.
4. Move only a separately authorized, retained stimulus through its fixture.
   Predict raw range, dwell, and event order before observing them.
5. Exercise the qualified contact without flexing a glass capsule. Compare
   raw level, stable state, and witness behavior through bounce.
6. Invoke shutdown. Verify LED inactivity separately from released input-pin
   state.

Remove USB for heat, odor, rail instability, reset, current-limit trip,
out-of-rail output, unexpected movement, specimen/source disagreement, a loose
stimulus, a cracked capsule, or an exceeded current budget. Reconfigure only
while unpowered. Never inject a live short.

## Narrative example

The canonical Mega sketch keeps the high-level loop visible:

```cpp
void loop ()
{
    const adk::TimePoint now (millis ());

    observeMagneticInputs (now);

    if (!decideEvidence () || !actuateEvidence ())
    {
        stopSafely ();
    }
}
```

The run ends independently after 120 seconds. Serial is optional and is not an
evidence requirement.

## Software evidence

Focused host tests cover lifecycle, threshold dwell, hysteresis, raw evidence,
out-of-range classification, rollover, backward time, invalid configuration,
busy claims, claim reuse, and ownership traits. The Mega sketch measures 4,872
bytes flash and 218 bytes static RAM under the pinned toolchain.

These are software results. No specimen pinout, voltage, transfer behavior,
stimulus, or bench observation is claimed.
