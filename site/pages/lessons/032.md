# Lesson 032 — quadrature rotary encoder

Status: **host verified; hardware acceptance open**  
Energy class: **E1** — USB-powered Mega, passive encoder contacts, and
resistor-limited LEDs
Safety boundary: **human input and low-voltage visual evidence only**

This lesson turns two sampled contact levels into a deterministic signed
position:

`phase A + phase B → Gray-code edge → delta + position + diagnostics`

The supported unit is one valid phase edge, not a vendor-dependent detent or
“click.” Clockwise traversal is `00 → 01 → 11 → 10 → 00`; the reverse path is
counterclockwise. Each valid edge contributes exactly `+1` or `-1`. A repeated
state contributes zero.

## Circuit and observation

Inspect the exact module before wiring. For the reference circuit, connect the
identified `CLK/A` signal to D24, `DT/B` to D25, the separate push switch to
D26, and the identified ground pin to Mega GND. Do not infer pin order from a
retail family name. The encoder component owns only D24 and D25; D26 remains a
separate `Button`.

| Evidence | Connection and meaning |
|---|---|
| TP-A | D24 relative to GND; sampled phase A |
| TP-B | D25 relative to GND; sampled phase B |
| position nibble | four resistor-limited LEDs show the low four position bits |
| state RGB | green pulse: valid edge; amber: no edge; red: invalid jump |

TP-A and TP-B expose contact behavior. The LEDs expose the decoder decision.
That distinction makes a wrong sequence, contact bounce, and a software
decision independently observable. Serial is optional supporting evidence.

## Decoder contract

`QuadratureEncoderConfig` names two distinct Mega digital pins, a supported
pull policy, and an optional direction reversal. Initialization validates both
pins, acquires A then B transactionally, configures both inputs, then samples A
followed by B once to establish the baseline. That first sample emits no
movement.

`update()` reads A once and B once in the same order. The snapshot reports:

- saturated signed `position`;
- current-update `delta` of `-1`, `0`, or `1`;
- `rotation`, current `phaseMask`, and complete `Status`;
- a saturating `invalidTransitions` count;
- whether the position reached its signed limit.

A two-bit jump such as `00 → 11` is invalid. Position and delta remain
unchanged, the invalid counter increments, and the new phase becomes the next
comparison baseline so decoding can recover. Bounce reversals are decoded
literally; the component does not guess a detent or conceal evidence.
`reversed` changes only the reported direction.

Position saturates at `INT32_MIN` and `INT32_MAX`; it never wraps.
`resetPosition()` changes the accumulated value and clears position saturation
without touching the hardware or phase baseline.

## Lifecycle and ownership

If B acquisition or configuration fails, initialization rolls A back before
returning the failure. Repeated successful initialization is inert.
`shutdown()` releases B then A, is idempotent, and preserves count evidence
while the snapshot reports `NotInitialized`. Destruction performs the same
cleanup. The component is neither copyable nor movable.

## Narrative sketch

```cpp
observeEncoder();
decideEncoderEvidence();
presentEncoderEvidence();
```

Setup acquires the encoder inputs, separate encoder button, four position
LEDs, and RGB indicator; configures outputs inactive; initializes the decoder;
then shows the ready state. The loop samples the two phases once, interprets
one stable snapshot, and presents the low position nibble plus edge validity.

## Predict, observe, interpret

1. With USB disconnected, verify identified module markings, common ground,
   D24/D25 phase paths, D26 switch path, and one resistor per LED channel.
2. Predict the TP-A/TP-B sequence for one slow turn before applying power.
3. Rotate through a complete sequence. Observe both test points and predict
   four signed edges, independent of the module’s mechanical detents.
4. Compare the phase sequence with the position nibble and valid-edge pulse.
   Interpret agreement as decoder evidence, not as proof of a generic module
   pinout.
5. Create only a safe contact-level invalid jump with an unpowered,
   pre-inspected fixture. Predict no position change and one red indication.
6. Invoke shutdown separately. Verify the LEDs become inactive, then verify
   input release independently before removing USB power.

Stop and remove USB power for heat, odor, resets, unstable levels, a signal
outside the Mega rail, unidentified pins, or disagreement between the module,
wiring table, and observations. Never move jumpers while powered.

## Software evidence

Deterministic tests cover all four initial phases, both directions, reversal,
partial turns, bounce, repeated states, every invalid jump and recovery,
position and diagnostic saturation, reset, exact read order, transactional
failures, lifecycle, traits, and byte-identical replay.

The visible adventure requires one positive edge, then one negative edge, then
the encoder switch. Those dependent discoveries end in a steady white reward;
the four position lamps remain live throughout. At 120 seconds every indicator
shuts down regardless of contact state or progress.

Repository automation owns compilation, tests, size, and publication. Those
maintainer gates do not establish the exact module pinout, voltage limits,
contact quality, output levels, or physical acceptance.
