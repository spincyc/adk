# Environmental station

Status: **host verified; hardware acceptance open**  
Energy class: **E1** — USB-powered, low-current learning instrument

This checkpoint composes scheduled DHT11 observations, stable locale-free
records, a 16x2 character display, and an RGB health indicator. It is a
learning instrument, not a calibrated weather station, alarm, or life-safety
monitor.

The run loop remains a visible evidence chain:

`observe sensor → record health → present LCD rows → indicate health`

`EnvironmentalStation` owns the lifecycle of its injected `ClimateSensor`.
The first update samples immediately; later records occur at explicit
deadlines. Early calls preserve the prior record. Late calls produce one new
record rather than a catch-up burst. Every record retains the sample state,
transport status, observation time, record time, and sequence.

Predict the record number and health before each scheduled observation.
Observe the LCD age/status field, the D5–D7 health cadence, and the D22/TP13
DATA transaction. Interpret them separately: the LCD explains the current
record, the cadence proves the loop remains observable, and TP13 exposes the
wire transaction. None of these alone proves climate accuracy.

The canonical Mega project uses D22 for DHT11 DATA, D30–D35 for a 16x2
HD44780-compatible LCD in 4-bit mode, and D5/D6/D7 through separate 330 Ω
resistors for the common-cathode RGB indicator. With power removed, verify the
exact sensor and LCD pin numbering against their primary documentation.

Host traces cover lifecycle rollback, exact cadence boundaries, late updates,
transport and validation faults, stale records, recovery, restart, rollover,
ambiguous time, and deterministic replay. Physical startup, values, timing,
current, reset, shutdown, and power-removal evidence remains deferred until
the bench card is completed. The canonical Mega build uses 14,110 bytes of
flash and 906 bytes of static RAM.
