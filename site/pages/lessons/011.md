# Timed traffic states

Energy class: **E1** — USB-powered, resistor-limited indicator LEDs

Build a miniature junction that explains itself with light:

`button event + explicit time → TrafficJunction → signal snapshot → LEDs`

Start with the main-road red/yellow/green chase. Add the interlocked side
road, then WALK/STOP, then the pedestrian request button. Each stage adds an
immediately visible payoff, and the final payoff only works when the earlier
wiring is right: a request waits for the vehicle sequence to finish, both
vehicle reds appear, and only then does WALK get its turn.

The exact build uses eight external LEDs and eight 330 Ω resistors: three red,
two yellow, and three green. D30–D35 are the two vehicle heads; D36–D37 are
WALK and STOP. D22 uses the Mega internal pull-up and a button to GND. D13 is
the Mega's built-in `L` LED, so it needs no external LED or resistor.

After upload, D13 flashes for 250 ms, pauses for 750 ms, and starts the show.
The junction runs for about two minutes, holds all-red for one second, then
releases every output. Press Mega RESET to play again. Disconnect USB before
moving wires.

Behind the scenes, automated checks cover every phase, request boundaries,
invalid configuration, time reversal, rollover, restart, and fault handling.
