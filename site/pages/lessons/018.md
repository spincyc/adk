# Make a keypad tell a story

Prerequisites: **Lessons 001–017**, especially Lesson 016's keypad
identification. Lesson 017's intent-versus-effect rule carries forward; its
servo and pointer do not.

This is a fast, inert project:

`4×4 keypad in 12-key mode → RGB story → D30 paper latch → optional LCD words`

A good four-key teaching pattern makes the RGB green and lights an LED behind
a paper drawing for three seconds. Wrong patterns make amber; three denials
begin a ten-second lockout. Nothing moves, protects property, authenticates a
person, or controls a door.

## Five quick payoffs

1. Wire the authorized 4×4 membrane keypad in 12-key mode. D13 gives a short
   acquisition flash.
2. Add the common-cathode RGB LED. Blue means ready; accepted digits make
   white.
3. Add the D30 LED behind a paper latch. `1 2 3 4 #` makes green and lights the
   prop.
4. If you have an exactly identified bare parallel LCD1602, add readable
   prompts.
5. Try a denial, lockout, automatic recovery, and then the good pattern again.

The adventure always ends after two minutes, regardless of key presses. It
commands visible outputs inactive, holds that state for 250 ms, releases
resources in reverse order, and waits for Reset.

The later reward depends on the earlier wiring. A wrong keypad map, chord,
held key, missing ground, or failed indicator prevents the green/D30 payoff.
There is no learner test card or instructor sign-off; automated code checks
remain behind the scenes.

## Literal wiring

The authorized keypad has sixteen keys and eight tail conductors. Identify all
eight with USB removed. Use R0–R3 and C0–C2; tape C3—the A/B/C/D column
conductor—by itself.

| Role | Mega connection | Visible result |
|---|---|---|
| keypad R0–R3 | D22–D25 | four scanned rows |
| keypad C0–C2 | D26–D28 | twelve active keys |
| keypad C3 | individually insulated | A/B/C/D inactive |
| common-cathode RGB | D5/D6/D7, each through its own resistor | state color |
| paper-latch LED | D30 through its own resistor | program “open” intent only |
| acquisition witness | built-in D13 | one 250 ms flash after acquisition |

Every LED channel needs its own resistor of at least 220 Ω. Confirm the RGB
package’s actual leg order from its documentation; packages differ.

## Optional LCD, conditional on exact identity

Use only a separately identified bare parallel HD44780-compatible LCD1602 with
the literal 16-pin header below. An I²C backpack or unknown module stays out.
The base sketch defaults `ADK_LESSON018_USE_LCD` to `0`, so an absent display
cannot block the other rewards. Change that definition to `1` only for this
exact LCD, compile again, and then wire it. RGB and D30 still tell the complete
story when the LCD stage is skipped.

| LCD pin | Connection |
|---|---|
| 1 VSS / 2 VDD | GND / 5 V |
| 3 VO | correctly wired 10 kΩ contrast-pot wiper |
| 4 RS / 5 RW / 6 E | D34 / GND / D35 |
| 11–14 D4–D7 | D36–D39 |
| 15 A / 16 K | leave open until exact backlight ratings are known |

## Expected story

| State | RGB | LCD, when fitted | D30 |
|---|---|---|---|
| ready | blue | `READY` | off |
| entering | white | `ENTER` plus count | off |
| granted | green | `GRANTED` | on for three seconds |
| denied | amber | `DENIED` | off |
| locked out | slow amber pulse | `LOCKED OUT` | off |
| fault | red | `FAULT` | off |

Color is never the only clue. The optional words and separate D30 LED repeat
the state meaning.

## If one stage does not appear

- No D13 flash: unplug and compare the seven active keypad conductors with the
  printable keypad plate.
- D13 works but color does not: inspect RGB identity, three resistors, and
  common ground.
- RGB works but D30 does not: inspect only the D30 resistor/LED branch.
- Indicators work but LCD is blank: preserve the working circuit; inspect
  exact LCD identity, contrast, RS/E, and D4–D7.
- Fault: release every key, remove USB, correct the loose or crossed
  connection, and restart.
