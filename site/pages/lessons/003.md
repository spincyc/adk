# Button and reaction timer

Status: **host verified; Mega hardware acceptance pending**

The first integration project combines D22 input, deterministic debounce,
explicit time, diagnostic output, and a hardware-neutral state engine. A saved
timestamped input trace reproduces every transition and result.

```cpp
const adk::TimePoint now (millis ());

button.update (now);
timer.update  (now, button);
led.set       (timer.snapshot ().ledOn);
```

HTML provides exact API links and errata. The PDF provides the D22/D8 bench
circuit, pencil orientation plate, timing diagrams, replay worksheets,
false-start experiments, and acceptance record.
