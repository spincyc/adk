# Lesson 003: common-cathode RGB LED

Control the three dies inside one RGB package independently and use PWM duty
cycle to mix visible colors.

## Outcomes

By the end, you can:

- verify a common-cathode RGB LED pinout;
- protect every color channel with its own resistor;
- use PWM-capable Mega pins for red, green, and blue;
- command `adk::led::Rgb` with current `adk::color` values;
- distinguish PWM duty cycle from PWM frequency; and
- compare predictions with repeated visual or instrument evidence.

## Prerequisites

- [Lesson 002](002.md)
- Comfortable tracing series LED branches and checking polarity
- Basic understanding of percentages and average values
- The RGB LED's manufacturer pinout or datasheet

## Bill of materials

- Arduino Mega 2560 and USB data cable
- Breadboard and jumper wires
- Verified common-cathode RGB LED
- Three 330 Ω resistors, one per color anode
- Optional multimeter
- Optional oscilloscope, logic analyzer, or phone slow-motion camera

An instrument is required to claim a PWM frequency measurement. Camera bands
and apparent brightness are observations, not frequency measurements.

## Safety

Disconnect all power before changing wiring. Confirm the package pinout; RGB
lead order is not universal. Connect the common cathode only to Mega GND and
use one resistor per anode. Inspect for adjacent leads touching and for a
5 V-to-GND short. Stop immediately for heat, odor, unexplained flicker, or a
reset loop.

## Current API and wiring

```cpp
adk::led::Rgb led (6, 5, 3);

const auto orange = adk::color::orange ();

adk::initialize ();
led.on          (orange);
```

The current constructor maps red, green, and blue to D6, D5, and D3
respectively. All three are PWM-capable Mega 2560 pins:

- D6 → 330 Ω resistor → red anode
- D5 → 330 Ω resistor → green anode
- D3 → 330 Ω resistor → blue anode
- common cathode → GND

This lesson and sketch assume a common-cathode part. A common-anode package
requires different wiring and inverted control and is not a drop-in
substitution.

PWM is rapid digital switching, not a true analog voltage. For an 8-bit channel
value `x`, the lesson uses the model `x / 255 × 100%` for duty cycle. Actual
frequency and endpoint behavior depend on the Arduino core, timer, and any
other library using that timer.
