# Deterministic Simon

Status: **engine host verified; hardware adapter experimental**<br>
Energy class: **E1** — low-voltage buttons, current-limited LEDs, and one
passive piezo

Simon is the second integration checkpoint. Four buttons become one complete
`SimonInput`; the hardware-neutral engine returns output intent in a
`SimonSnapshot`. It never reads pins, drives cues, sleeps, allocates, or consults
a hidden clock.

```cpp
buttons[0].update (now);
buttons[1].update (now);
buttons[2].update (now);
buttons[3].update (now);

const adk::Status status = game.update (now, input);
const adk::SimonSnapshot state = game.snapshot ();
```

The HTML reference defines the interface boundary. The PDF supplies the full
four-button, cue-LED, RGB, and passive-piezo circuit; state diagram; golden
replay; fault matrix; current budget; and staged hardware acceptance procedure.
