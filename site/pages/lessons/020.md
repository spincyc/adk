# The direction chase

Prerequisites: **Lessons 001–019**

Status: **host verified; physical observation open**

Build three tiny LED paths and get a complete ten-second show: dim forward,
bright forward, a deliberate all-dark reversal, reverse, stop, then a faster
second round. At ten seconds the sketch shuts itself down.

This is the complete supported circuit:

| Lamp | Mega pin | Complete path |
|---|---:|---|
| Forward / TP-F | D22 | D22 → 1 kΩ → LED long leg; short leg → negative rail |
| Reverse / TP-R | D23 | D23 → 1 kΩ → LED long leg; short leg → negative rail |
| Enable / TP-E | D6 | D6 → 1 kΩ → LED long leg; short leg → negative rail |
| Return | GND | Mega GND → negative rail |

Use one resistor per LED. Unplug USB before moving any wire.

The experiment is intentionally inert. **Do not connect an H-bridge, motor,
motor supply, relay, or wheel.** The authorized kit-family listings do not
establish an exact motor or driver electrical identity.

## Build for visible payoffs

1. Build D22 and D23 as separate direction lamps.
2. Add D6 as the enable lamp. It will visibly change PWM brightness.
3. Upload the canonical sketch and watch each direction handoff.

The reverse lamp cannot take over immediately. A reversal first applies zero
duty and makes both direction outputs inactive. Only after 250 ms may the
opposite direction and enable return. This blackout makes the safety rule part
of the show.

## Read the show

| Time | Visible result |
|---:|---|
| 0.00–0.75 s | all dark: ready |
| 0.75–1.75 s | forward + dim enable |
| 1.75–2.75 s | forward + bright enable |
| 2.75 s | all dark for the reversal deadline |
| about 3.00–4.50 s | reverse + bright enable |
| 4.50–5.50 s | stopped |
| 5.50–6.50 s | forward + bright enable |
| 6.50 s | second all-dark reversal |
| about 6.75–8.00 s | reverse + bright enable |
| 8.00–10.00 s | stopped |
| after 10.00 s | automatic shutdown; all dark |

The adapter writes only the **applied** snapshot. Requested and applied
direction can therefore differ during dead time without either output lying
about the decision.

## If it looks wrong

- One missing direction usually means a reversed LED or broken series path.
- Both directions together suggests shared breadboard rows or a D22/D23 short.
- Working direction with no enable points to the D6 path.
- No brightness change suggests the enable jumper is not really on PWM pin D6.
- Lights after ten seconds mean reset once, then disconnect USB if it repeats.

Automated repository tests cover the deadline edges, both reversals, stop
dominance, invalid input, time wraparound, rollback, and shutdown. They remain
behind the scenes; the learner gets the visible chase.

A powered continuation would require an exactly identified motor and driver,
primary datasheets, measured stall current, a separate current-limited supply,
flyback path, physical disconnect, and guarded unloaded fixture. That is a
separate E2 qualification, not part of this lesson.
