# Synthetic channel assessment

Status: **host verified; hardware acceptance open**
Energy class: **E1** — USB-powered Mega, passive buttons, and resistor-limited LEDs
Safety boundary: **learner-operated simulation only**

This lesson turns two explicit synthetic observations into one stable
assessment:

`primary + redundant + local age → assessed inert channel state`

`InertChannelAssessor` supports eight fixed channels without allocation. It
classifies `Open`, `Closed`, `ShortSimulated`, `Stale`, `Contradictory`, and
`Unavailable`. Those words describe only this teaching fixture. They do not
diagnose an initiator, prove an energetic circuit safe, or authorize an output.

## Circuit and evidence

| Role | Mega pins | Connection |
|---|---|---|
| Channel indicators / TP29 | D22–D29 | each pin → 1 kΩ → LED anode; cathode → GND |
| Channel, primary, redundant, apply | D30–D33 | momentary switch from pin to GND |
| Input test point / TP28 | selected D30–D33 pin | measure relative to Mega GND |

The four buttons cycle the selected channel and the two synthetic observations,
then apply the complete eight-channel set transactionally. The eight indicators
show the latest assessment:

| Assessment | Indicator |
|---|---|
| open | off |
| closed | steady |
| short-simulated | 1 s on, 1 s off |
| stale | one 200 ms pulse each second |
| contradictory | 200 ms alternating cadence |
| unavailable | two 120 ms pulses every 2 s |

The startup response proves resource acquisition. Shutdown is a separate test:
measure TP29 rather than inferring high impedance from a dark LED.

## Assessment contract

Matching usable observations produce their matching state. Different usable
observations are contradictory. If either observation is unavailable, the
result is unavailable. Age beyond the configured threshold dominates those
classifications and produces stale.

The exact stale boundary is inclusive on the fresh side: age equal to
`staleAfter` retains the underlying classification; the first greater age is
stale. Timestamp comparisons use the unambiguous half of the 32-bit space.

`update()` validates the complete submitted set before changing any slot. It
rejects an out-of-range channel, duplicate channel, invalid enum value, future
timestamp, excessive count, or null nonempty input. A rejected update preserves
the preceding assessments.

An omitted channel retains its last accepted observation. A channel that has
never appeared is unavailable.

## Recorded deterministic source

`RecordedInertObservationSource` replays caller-owned, immutable sets. Each set
contains all eight channels. Times must be strictly increasing in the
unambiguous timestamp window. A delayed call selects the latest due complete
set; it does not emit a catch-up burst.

The source and assessor remain separate deliberately:

- the source decides which evidence is due;
- the assessor validates and stores submitted evidence;
- `assessment()` applies local age at the caller-supplied time;
- the example alone maps a state to an LED cadence.

That separation lets a later simulator replace the prerecorded source without
changing the assessment rules.

## Narrative run loop

```cpp
observeOperator   (now);
decideAssessments (now);
showAssessments   (now);
```

Objects appear in dependency order: runtime, buttons, LEDs, assessor, then
observation values. Setup acquires every owner, configures the initial synthetic
set, and starts the panel. The loop observes button events, decides only when
Apply creates a new complete set, and presents all assessments.

The sketch contains no relay, external-load driver, radio, captured protocol,
callback, or generic actuation sink.

## Predict, observe, interpret

1. Unpowered, verify every LED has its own resistor and every switch closes only
   to GND.
2. Predict Open/Open leaves an indicator off and Closed/Closed makes it steady.
3. Predict Open/Closed produces the fast contradictory cadence.
4. Predict either Unavailable input produces the double pulse.
5. Stop applying updates and predict the slow stale pulse after five seconds.
6. Observe TP28 and TP29 against GND; interpret agreement as evidence for this
   synthetic model only.
7. Invoke shutdown and measure TP29 separately for the safe-state check.
