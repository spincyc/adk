# PWM output and RGB LED

Status: **host verified; Mega hardware acceptance pending**<br>
Energy class: **E1** — low-voltage Mega GPIO and current-limited LEDs

`PwmOutput` owns a PWM-capable pin and an appropriate shared timer lease.
`RgbLed` composes three endpoints transactionally, so a failed channel claim
rolls back the earlier claims.

```cpp
adk::Runtime runtime;
adk::RgbLed  led (runtime.resources (),
                  {6, 220},
                  {5, 220},
                  {3, 220});

if (led.initialize ().ok ())
{
    led.set (adk::Rgb (255, 64, 0));
}
```

This lesson uses a common-cathode RGB LED. Package lead order is not universal:
build from the PDF schematic, connection table, and the part datasheet. The
finite example transactionally adds an acquisition-only `MonoLed` at
TP-ACQ/D13: it emits a 250 ms factory-LED pulse and a 750 ms dark separator
while the RGB package remains off. Six one-second RGB behavior colors follow,
then controlled shutdown releases D13 and all three RGB pins. The PDF names
TP-ACQ/D13, TP-R/D6, TP-G/D5, and TP-B/D3 and carries current calculations,
predict--observe--interpret records, a one-channel-at-a-time weak-bias
safe-state procedure, reset and power-removal checks, and the complete bench
acceptance card. No physical result is claimed until that card is performed
and reviewed.
Per-channel current is calculated from measured resistor drop and resistance;
the white-step total is recorded. Power removal is measured at the 5 V rail
and every named test point, not inferred from dark LEDs.
