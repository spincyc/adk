# Moisture evidence and owned buses

Status: **host verified; physical acceptance open**
Primary experiment: **E1** — USB-powered Mega and resistor-limited evidence LEDs
Transport: **deterministic recording drivers; no physical bus waveform**

Lesson 022 turns a repeatable analog observation into a bounded record while
introducing explicit ownership for I2C and SPI:

`TP-M/A0 → MoistureSensor → MoistureSample → owned device → record`

The first-class lesson claims one I2C resource and one SPI resource, gives devices
explicit owned relationships, validates transaction arguments and timeouts,
performs a synchronous driver call, and releases its claims during shutdown or
destruction. It does not expose global `Wire` or `SPI` ownership and does not
retain caller buffers.

Device relationships, bounded timeout values, Mega fixed-pin ownership,
chip-select restoration, and direct AVR backends now exist and have
deterministic host tests. This recording-driver sketch deliberately generates
no bus waveform; exact-device and physical Mega observations remain open.

## Observable software experiment

The reference circuit uses a 10 kΩ potentiometer as a controlled, repeatable
moisture-source simulator. Its outer terminals connect to 5 V and GND; its
wiper connects to A0/D54 at **TP-M**. It is not a soil probe and makes no claim
about soil physics.

The canonical lesson uses that real analog observation plus sketch-local
recording drivers:

- D13 pulses from 100 ms at 0 permille to 900 ms at 1000 permille after a
  valid sample is recorded;
- D12 latches a fault indication after a failed status;
- D49 is only the SPI device's logical chip-select resource identifier;
- D20, D21, D50, D51, and D52 remain physically open.

A D13 pulse follows a valid sample, valid simulated clock state,
recording-driver transfers, append, and successful `sync()`. It supports the
software path and fixed in-memory durability model. It proves no I2C
acknowledgement, SPI waveform, voltage compatibility, RTC response, SD-media
durability, or power-loss retention. TP-M is the independent electrical
observation.

| Signal | Mega pin | Lesson connection |
|---|---:|---|
| Moisture input / TP-M | A0 / D54 | 10 kΩ potentiometer wiper |
| Potentiometer rails | 5 V / GND | one outer terminal to each rail |
| Activity evidence | D13 | built-in LED; 100–900 ms pulse |
| Fault evidence | D12 | D12 → 1 kΩ → LED anode; cathode → GND |
| Logical chip select | D49 | leave physically open |
| I2C pins | D20/D21 | leave physically open |
| SPI pins | D50/D51/D52 | leave physically open |

Remove USB power before wiring or moving a probe. No peripheral, motor, relay,
external supply, or load belongs in this experiment.

## Moisture sample contract

The reference calibration is `{dryReading: 200, wetReading: 800,
faultMargin: 32}`:

| Raw reading | State | Moisture |
|---:|---|---:|
| 200 | `Valid` | 0 permille |
| 500 | `Valid` | 500 permille |
| 800 | `Valid` | 1000 permille |

The mapper uses signed boundary comparisons, integer-only nearest rounding,
and clamping after validity checks. Ascending and descending endpoints both
work. The state remains separate from the numeric field:

- `Unavailable`: no accepted update or the sensor is shut down;
- `Valid`: calibrated 0–1000 permille;
- `InputBelowRange` / `InputAboveRange`: suspected electrical-range fault;
- `Stale`: the last valid observation is older than caller policy.

ADC counts are ratios to the measured reference rail. Measure TP-M relative to
GND; do not present a count as a voltage without measuring the rail. A future
soil probe needs exact module identity, supply/output limits, source impedance,
common-ground and corrosion policy, and its own bench record.

## Clock and durable-prefix contract

`Rtc::read()` returns `Result<ClockReading>`. Transport status and clock state
remain separate. Only `Valid` permits raw Unix seconds in a record. `NotSet`
and `OscillatorStopped` reject the timestamp even after successful transport;
`TransportFault` preserves the failed transport meaning.

The sketch uses `SimulatedRtc`, which starts from a fixed value and advances
deterministically. It is not an I2C RTC adapter and does not persist through
board reset or power removal.

`Storage::append()` stages bytes. Only `Storage::sync()` advances the durable
prefix. The sketch's `FixedStorageMedium` is a bounded 512-byte in-memory
model:

- partial append failure retains the exact staged prefix;
- failed sync can be retried without re-appending;
- shutdown, destruction, or restart discards an unsynchronized suffix;
- a new `FixedStorage` owner resumes from the medium's durable prefix;
- capacity exhaustion fails without overwriting earlier bytes.

Every eighth committed record, the sketch restarts the storage owner and
compares staged and durable sizes. This demonstrates session recovery in one
running program, not SD-media or power-loss recovery.

The fixed 11-byte record stores Unix seconds, clock state, raw ADC count,
moisture permille, moisture state, and one synthetic I2C metadata token in an
explicit byte order. The same bytes pass through the recording SPI device and
the in-memory storage model.

## Lifecycle contract under review

Construction is inert. `initialize()` claims the bus resource and configures
the injected driver. A failed configuration disables the driver and rolls the
claim back. Repeated initialization and shutdown are idempotent. Destruction
calls shutdown.

The bus owner validates:

- I2C 7-bit non-reserved addresses from 0x08 through 0x77;
- I2C write and read buffers independently, each currently up to 32 bytes;
- SPI clock greater than zero, modes 0–3, and 1–256 bytes;
- at least one non-null SPI data direction;
- a claimable SPI chip-select pin.

The caller owns every buffer before, during, and after the synchronous call.
No callback or queued operation survives `transfer()`.

## Status flow

Pass the complete value to the observation or policy boundary:

```cpp
const adk::Status status =
    metadataDevice.transfer (writeData, writeSize, readData, readSize,
                             adk::Duration (20));

if (!status.ok ())
{
    observeFailure (status);
}
```

Use `error()` only for a branch that needs the underlying `StatusCode`.
`transient()` classifies a potentially recoverable cause; it does not authorize
an unbounded retry. A retry policy belongs above the bus and must remain
bounded, deterministic, and observable.

## What must improve before promotion

1. Finish shared integration, package registration, and complete quality gates.
2. Select exact RTC and storage specimens from primary datasheets; the
   simulated RTC and fixed memory are not physical adapters.
3. Record physical timeout, fixed-pin, and chip-select-restoration evidence on
   a Mega 2560; host traces are not electrical measurements.
4. Complete the potentiometer and bus-adapter bench card without replacing the
   circuit with a soil probe.

## Predict, observe, interpret

- **Acquire:** predict that a busy bus prevents driver configuration. Observe
  the host operation record. Interpret whether rollback released every claim.
- **Moisture:** predict raw 200, 500, and 800 map to 0, 500, and 1000
  permille. Observe TP-M and the corresponding D13 pulse durations.
- **Transfer:** predict exact address, settings, 11 record bytes, and synthetic
  token. Replay twice. Equal records support determinism, not electrical
  transport.
- **Durability:** fail append at every byte, fail and retry sync, then restart
  with an unsynchronized suffix. Distinguish staged from durable size.
- **Conflict:** claim D49 elsewhere. Predict the SPI driver is never called.
- **Shutdown:** host tests prove resource reuse and adapter restoration.
  Physical pin restoration remains unmeasured until the Mega bench card is
  completed with exact devices.
- **Evidence:** distinguish a D13 software acknowledgement from open physical
  SDA/SCL/MOSI/MISO/SCK/CS logic-analyzer evidence.
