# Select the Library Manager lint mode by registry phase

ADK has no recorded official Library Manager inclusion. The current release
gate and CI therefore run strict structural lint plus the `submit` rules.
Separate `submit` and `update` Make targets remain available, but `update`
becomes the release mode only after official index membership is independently
confirmed and recorded.

Arduino Lint remains pinned to 1.3.0 in CI. A local release gate must use the
same version, begin from a clean committed tree, and test the Arduino and native
archive consumers. It does not tag, push, publish, deploy, or submit.

The Arduino export excludes generated PDFs and internal development/research
material. Learner documentation remains published through the site and tracked
repository, while the installable library archive contains metadata, license,
README, changelog, public sources, and canonical examples.
