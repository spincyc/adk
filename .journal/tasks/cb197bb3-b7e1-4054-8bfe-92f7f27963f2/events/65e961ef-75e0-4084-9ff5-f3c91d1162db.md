# Complete native C++ consumer packaging

Added a deterministic `adk-native` C++17 source export containing public
declaration headers, an explicit Arduino-header-free source inventory, scope
documentation, license, and project README. The export normalizes file modes,
member order, ownership, timestamps, and gzip metadata; consecutive builds are
byte-identical.

The clean consumer gate preflights archive paths and entry types, extracts only
into a temporary directory, compiles every manifest source, creates a
deterministic `libadk.a`, then links and runs an `InertChannelAssessor`
consumer without repository-relative inputs. Documentation explicitly limits
the evidence to that portable value boundary: it makes no system-install,
package-manager, ABI, CMake, pkg-config, or native-hardware claim.

Native export, repeat-hash reproducibility, clean consumer, POSIX syntax,
style, headers, site, whitespace, and the independent committed Arduino
package-smoke gate pass.
