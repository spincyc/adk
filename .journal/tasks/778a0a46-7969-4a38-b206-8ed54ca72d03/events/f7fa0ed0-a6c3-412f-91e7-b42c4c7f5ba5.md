# Expand illustration guidance to hands-on projects

Audit every hands-on project, with the potato launcher first, for ample useful
pencil drawings. Visual progress indicators are a primary teaching tool.
Prefer multiple complementary drawings—overview, exact wiring, staged
assembly, checkpoints, expected visible state, and targeted troubleshooting—
over decorative repetition. Document this as durable curriculum guidance.

Pending clarification, prioritize buildable Arduino and mechanical projects;
add research-track pencil diagrams only where they clarify a real assembly or
signal path.
