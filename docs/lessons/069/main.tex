\lessonbox{\textbf{Responsibility.}
\texttt{QualifiedMotionRecorder} accepts one atomic copied qualification
envelope, advances a versioned hand-motion script, appends a bounded
caller-owned trace, and publishes inert presentation intent. It does not
sample a sensor, choose between sources, drive an endpoint, read a clock,
write a file, or establish durability.}

\section{Make interchangeability a configuration property}
The same recorder contract can serve separately configured sessions. A
session fixes exactly one source identity and its schema, normalization,
mapping, calibration, qualification, script, and presentation revisions.
Starting with one source and quietly accepting another is not
interchangeability; it is an unproved source switch.

\section{Accept one envelope, not two snapshots}
The input binds the complete Lesson 067 normalized record to the complete
Lesson 068 qualification witness for that exact record. Source identity,
revisions, sample sequence, observation time, qualification attempt, state,
reason, and evidence digest must agree. A digest helps detect a collision; it
never replaces comparison of the authoritative fields.

Reading one mutable record and then a separately mutable decision could join
evidence from different instants. The recorder therefore validates one copied
envelope before it changes any session state.

\begin{tabularx}{\linewidth}{@{}l X X@{}}
\toprule

record/witness mismatch & reject as correlation fault & none\\

byte-identical duplicate & idempotent replay & none\\
\bottomrule

\section{Append without silent loss}
The caller owns fixed-capacity trace storage. A qualified update stages a
complete canonical cell, validates it, writes it to the next free slot, and
then commits count, recorder sequence, script progress, and result together.
If validation or capacity fails, the prior policy, output canaries, and every
trace byte remain unchanged.

The trace never wraps, overwrites its oldest cell, silently coalesces samples,
or reports a dropped sample as recorded. The last free slot may be filled;
the next otherwise valid update reports \texttt{TraceFull}. Record-sequence
exhaustion faults before it can wrap to zero.

\lessonbox{\textbf{Volatile boundary.}
Here ``recorded'' means copied into caller-owned memory during this process
lifetime. It does not mean that media acknowledged a write, a filesystem
committed, a clock was accurate, or evidence survives reset or power loss.}

\newpage
\section{Give the trace a normative image}
Record identity is an explicit fixed-width encoding with magic, format and
length, source and revision identity, session and recorder sequences,
observation time, qualification attempt, script step, normalized values,
quality, orientation, health, reserved-zero fields, and an integrity check.
Field order, widths, signed representation, and byte order are part of that
contract. C++ padding, an address, or \texttt{memcmp} of public objects is
never record identity.

\begin{enumerate}
 \item Corrupt one reserved byte. Predict the decode result: \longblank.
 \item Replay a byte-identical accepted envelope. New trace count:
       \blankline.
 \item Change one vector component while retaining its sequence. Outcome:
       \longblank.
\end{enumerate}

\section{Advance a script only on accepted evidence}
Each accepted record belongs to the current versioned hand-motion step before
the completion predicate advances the script. Rejected, stale, saturated,
unqualified, or duplicate evidence cannot advance it. The terminal step stays
terminal until reset.

Lesson 044 remains the only pitch/roll presentation algorithm. Lesson 069
feeds it the qualification-frame sample and copies its result into intent; it
does not invent another orientation convention. Record sequence, source
sequence, qualification attempt, session generation, and script step remain
different values even when a fixture makes their numbers happen to match.

\section{Let faults dominate presentation}
Presentation is copied intent: source and recorder health, script prompt and
progress, orientation value-or-fault, trace count and full indication,
character-display tokens, and RGB color/blink tokens. It owns no pins and
causes no electrical action.

\section{Treat modular ordering deliberately}
Supplied time is modular \texttt{TimePoint}, never silently UTC. Equal
sequence/time is idempotent only for byte-identical evidence. Regression,
future observation, changed duplicates, exact half-range ambiguity, age beyond
the configured inclusive boundary, and exhaustion reject atomically.

At the exact maximum-age boundary evidence is \blankline; one representable
tick later it is \blankline. Explain why a signed cast is not a proof of
modular order: \longblank.

\section{Replay without touching hardware}
The canonical Mega sketch constructs copied records and qualification
witnesses, supplies time, invokes the recorder, and copies health, script,
orientation validity, trace count, capacity state, RGB intent, and display
intent into named volatile result cells.

\begin{center}
% ADK visual: pencil
\includegraphics[width=0.94\linewidth,height=2.18in,keepaspectratio]
 {069-replay-notebook-pencil.png}

\small\textit{Alternative text: rough graphite replay cards point into a
caller-owned lined notebook and then named result cells; a caption identifies
the notebook as volatile evidence rather than a disk receipt.}
\end{center}

\begin{enumerate}
 \item \textbf{Predict:} write the accepted source, health, current script
       step, orientation validity, trace count, and presentation tokens.
 \item \textbf{Observe:} compile for Mega 2560 and inspect the named volatile
       cells in a debugger, simulator, or disassembly. Serial may support the
       observation but is not required.
 \item \textbf{Interpret:} compare the complete copied envelope, resulting
       trace cell, script attribution, count, and fault intent. Explain any
       disagreement before changing the fixture.
\end{enumerate}

This is the E0 non-Serial observation path. It proves deterministic software
publication separately from electrical acquisition and safe state. E0 owns no
endpoint, so physical resource-acquisition and released-line evidence remain
open.

\section{Stress the complete project}
Exercise capacity one, one-before-full, full, unchanged duplicate, changed
duplicate, ordinary rollover, exact half-range ambiguity, source fault,
qualification rejection, stale evidence, reset, repeated shutdown, and
reinitialize. For each rejection, prove both the recorder state and every
caller-owned trace byte are unchanged.

The maximum composition includes Lessons 043, 044, 067, 068, and 069,
the largest qualification window, staged cell, complete envelope, orientation
result, presentation result, and maximum caller-owned trace counted exactly
once. It performs bounded work per update: no polling, acquisition wait,
display refresh loop, media retry, or unbounded catch-up.

\section{Draw the powered boundary}
There is no wiring diagram or formal schematic at E0. A future implementation
must split acceptance into independently qualified work:

\begin{itemize}
 \item exact sensor chip/carrier, I2C identity, voltage, pull-ups, scaling,
       data-ready behavior, mounting, and calibration;
 \item exact display, RGB LED, and button ownership, polarity, current,
       startup, self-test, fault dominance, and safe state;
 \item exact RTC, SD/media, timestamp domain, transaction receipts, schema,
       corruption and torn-write recovery, capacity, wear, removal, and
       power-loss durability.
\end{itemize}

This lesson authorizes only hand motion of an inert identified board. It
authorizes no motor, vehicle control, launcher, ignition, stored-energy
release, or unattended moving load.

\section{Exercises and acceptance reasoning}
\begin{enumerate}
 \item Run two separate sessions with different copied source identities.
       Show why neither session contains a midstream substitution.
 \item Pair a fresh record with an older qualified witness. List every
       observable byte and state value that must remain unchanged.
 \item Fill the last trace cell, then offer one fresh qualified envelope.
       Distinguish ``full'' from source fault and from durable storage.
 \item Inject source fault while retaining a plausible cached angle. Explain
       the required orientation and RGB/display intent.
 \item Corrupt each canonical image field class: framing, enum, reserved,
       payload, and integrity. Confirm decoding never partly publishes.
 \item List the physical evidence needed before replacing copied fixtures
       with one exact sensor, display, clock, and media assembly.
\end{enumerate}
