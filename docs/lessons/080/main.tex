\texttt{SmallIndicatorSemanticsPolicy} interprets one closed indicator

and one independently attributable observation. It owns no pin, endpoint,

\section{Separate appearance from meaning}
A small board that lights or sounds can still conceal its polarity, populated
resistor, driver, autonomous behavior, or required safe state. A retail label
does not settle those facts. E0 accepts only copied, correlated declarations
and observations; it never identifies or energizes a specimen.

\section{Bind the driver, not just its familiar fields}
The copied drive must match specimen, revision, electrical evidence, policy
configuration, lifecycle, session, run, step, and request correlation. It
must also carry the expected full Lesson 079 descriptor digest. That digest
binds family, source packet, topology, protection, and every budget field that
partial comparison would miss. Digest zero is valid; it does not mean absent.

\newpage
\section{Select meaning before observing it}
\texttt{SmallIndicatorSemanticRequest} is the L080-owned copied authority for
the expected semantic selection. Its nonzero request identity is repeated by
the observation and result. The selection never comes from the observation
being judged: otherwise a multichannel observation could declare the color
it was meant to prove.

Selected, observed, and semantic masks must be subsets of the declared mask.
A follows-drive request selects exactly one declared channel while drive is
active and zero while off. Autonomous requests select the complete declared
mask as enable authority; their observations may report a nonzero declared
subset. Observation-only requests select zero and never gain drive authority.
Inactive evidence uses zero.

Every unlisted structural combination is malformed and cannot mutate state.
Within the listed Active and Alternating rows, level, transition, and

semantic disagreements. \texttt{copiedLevelHigh} should equal the nonzero
mask for single-channel Buzzer and Voltage rows; a contrary value is a
\texttt{PolarityMismatch}. It should be false for multichannel kinds; a true
value is likewise a reachable mismatch, not erased during parsing. No mask
implies a pin count or wiring topology.

\section{Keep autonomous behavior explicit}
An Auto Flash LED does not become “active” merely because drive intent was
admitted. Its copied observation must show a declared nonzero subset and an
autonomous transition. Conversely, transition evidence on a follows-drive
Traffic Light is unexpected autonomy. E0 records only that a transition was
copied; cadence, duty, brightness, color accuracy, and waveform remain open.

\newpage
\section{Treat three streams and timing checks independently}
The request and observation have distinct attributable producer streams:
each has its own latched source/configuration and contiguous sequence. A
shared policy sequence orders apply and cancel. The first accepted apply uses
one in all three streams; each then advances independently. Wrap from maximum
to zero is exhaustion, not a restart. A cancel advances only the policy
stream and must use request-producer authority.

The caller supplies session start, request time, observation time, and current
time. The policy reads no clock. It enforces
\(startedAt \le requestedAt \le observedAt \le now\) with forward modular
half-range comparisons. Warm-up is computed from current time minus session
start; settling from observation time minus request time. No copied
``satisfied'' Boolean substitutes. Age equal to the declared maximum is
current; one tick older is stale.

\begin{enumerate}
 \item A safe-state observation does not prove drive admission.
 \item A fresh observation does not prove warm-up or settling.
 \item An admitted drive does not prove optical or acoustic behavior.
 \item Missing observation is incomplete; it never means inactive.
\end{enumerate}

Known-zero warm-up or settling requires no delay. Otherwise both computed
checks must pass independently. Safe-state evidence is independent again:
\texttt{DriveInactive}, \texttt{HighImpedanceRequired}, and
\texttt{UnpoweredRequired} are semantic declarations whose physical truth
still requires a later exact fixture and observed bench record.

\section{Replay without energizing a module}
The Mega sketch builds copied descriptors and fixtures for all five concrete
kinds. It applies correlated drive intents, semantic requests, and
observations, then copies results into named volatile cells. It performs no GPIO, timing,
waveform, optical, acoustic, or supply operation.

\begin{enumerate}
 \item \textbf{Predict} disposition, reason, semantic mask, autonomy flag, and
       safe-state flag before each call.
 \item \textbf{Observe} named volatile cells with a debugger, simulator, or
       disassembly. Serial is optional and never sole evidence.
 \item \textbf{Interpret} agreement as deterministic E0 semantic evidence,
       never as proof that a physical indicator lit, blinked, or sounded.
\end{enumerate}

\lessonbox{\textbf{Atomicity experiment.}
Place recognizable canaries around the output result. Submit a changed
duplicate, digest mismatch, reserved mask bit, a gap in each of the three
streams, future time, and malformed observation. Confirm that each structural
or correlation API rejection preserves the policy, output, and canaries.
Contrast a terminal chronology or well-formed semantic disagreement, which
commits an attributable rejected result for byte-identical replay.}

 \item Exhaust all enum encodings and every kind/autonomy/safe-state/polarity/
       population/mask cross-product.
 \item Exercise exact request selections for all five fixtures, every
       structurally attributable observation row, and every reachable

 \item Mutate every driver correlation field and the full descriptor digest;
       retain literal digest goldens independent of production code.
 \item Test computed warm-up/settling, freshness equality/one-over, rollover,

       observation sources, duplicates, gaps, cancellation, and shutdown.
 \item Test every canonical and malformed Lesson 079 mapping tuple.
 \item Cross producer, stop, stale, warm-up, settling, polarity, autonomy,
       observation, and safe-state failures at every precedence boundary.
\end{itemize}
